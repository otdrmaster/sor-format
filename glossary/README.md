# OTDR glossary in 15 languages

Terms a fiber technician meets on every OTDR trace, in fifteen languages. Each term is the word people in that language actually use at work, not a word-by-word translation. Where an instrument maker ships its software in that language, its wording served as the reference.

English and Russian were written and reviewed by people. The other thirteen were checked against vendor software where such software exists. Hindi and Arabic have no vendor reference at all and still need a native speaker. If a term looks wrong in your language, open an issue.
